# Infinopt GitHub defaults

This repository contains default issue forms and a pull request template for Infinopt repositories.
GitHub uses these defaults when a repository does not define its own templates of the same type.
A repository with its own issue templates or issue template configuration uses those instead of the default issue template directory.

The forms guide contributors who use GitHub's template chooser. Required fields do not validate issues created through the API or edited later. The pull request template does not enforce its sections. Use separate automation if a repository needs to enforce these requirements.

See [GitHub's documentation on default community health files](https://docs.github.com/en/communities/setting-up-your-project-for-healthy-contributions/creating-a-default-community-health-file) for the lookup rules.
